# CppOverdub
A header-only,single file audio library for C++, making it easier to process

Source of inspiration : [pydub](https://github.com/jiaaro/pydub)

Requirements: [ffmpeg](https://ffmpeg.org/)

[openal-soft](https://github.com/kcat/openal-soft)

Current Version: 20260110

API unimplemented:
+ AudioSegment::doFade
+ AudioSegment::doFilterLow
+ AudioSegment::doFilterHigh
+ AudioSegment::doGain
+ AudioSegment::doNormalize
+ AudioSegment::doOverlay
+ AudioSegment::doSpeedUp
+ AudioSegment::doSplitChannels
+ AudioSegment::doSplitOnSilence
+ AudioSegment::doStripSilence
+ AudioSegment::fromChannels
